# 커밋별 복습

코드·실험·글을 추가한 커밋을 오래된 순서로 읽는다. 문서 포장 커밋 자체는 재귀적으로 설명하지 않는다. 각 HTML의 파일 링크는 현재 checkout으로 이어지므로, 당시 내용은 표기한 SHA의 `git show`로 확인한다. HTML의 Mermaid는 CDN을 사용하며 네트워크가 없으면 원문 다이어그램 텍스트를 읽을 수 있다. 브라우저 화면 검증은 미완료다.
